# .github

Default community health files for all my repositories.

Files in this repository are automatically used by any repo that doesn't
define its own version:

- `PULL_REQUEST_TEMPLATE.md` — shown when opening a pull request
- `ISSUE_TEMPLATE/` — the issue chooser (bug report, feature request)

Docs: <https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file>
